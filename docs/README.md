## 当前运行链路

```text
React UI
  → FastAPI 创建任务
  → 数据库租约调度
  → AgentExecutor
  → LangGraph 主工作流与子图
  → 原子音频/MIDI 工具
  → checkpoint + 任务数据库
  → 持久化事件 → WebSocket 回放
```
