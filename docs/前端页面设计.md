# 设计思路
在前端页面设计过程中，我们拟通过“*确定基本设置（主色调、内容分布等）→大语言模型生成提示词→Stitch生成静态原始页面→Penpot/Figma进行修改、动态页面设计*”的总体流程进行前端页面的设计。
我们拟设计*中英文两个版本*的前端页面，整体使用蓝白色调，符合常见Agent应用的设计逻辑与规范。

# 组件设计描述
## 顶栏
左侧：Logo、Open side bar、开启新对话
右侧：语言设置（简体中文、English）、用户头像（点击跳转DashBoard）
## TODO：左侧边栏
## 聊天页
用户输入前，页面居中显示引导词与对话框。
用户输入后，页面从上到下包括：
- 历史聊天内容
    - 用户输入（自然语言文字与音频文件）
    - Agent思考过程
    - Agent结果输出
- （若打开）专业参数设置框
- 对话框
其中专业参数设置框与对话框悬浮于历史聊天内容上方。
