# 项目简介
本项目是一个**AI音乐改编Agent Web应用**，用户只需上传自己喜欢的音乐音频，并用自然语言描述想要的风格，Agent将自动完成：音乐分析 → 主旋律/和弦提取 → MIDI生成 → 乐器改编 → 智能截取 → 渲染输出为独特纯音乐铃声。系统预计支持多轮对话优化，Agent会记住用户的修改意见并迭代改进，最终生成符合个性化需求的MP3铃声。

**技术定位**：南京大学2026年春季学期软工三课程项目，不涉及商业版权，重点展示Agent的规划、决策与反思能力，以及全栈工程化设计。

# 核心功能
## 1. 用户输入
- 用户主动上传本地音频文件（支持MP3/WAV)
- （可选）用户直接搜索可用的音频
- 用户输入自然语言描述改编目标（如“温柔钢琴风”“清晨阳光般的铃声”）
## 2. 智能需求理解
- Agent自主解析模糊需求，转化为技术参数（乐器、节奏、长度、情绪）
- Agent根据模糊需求选择合适工具
- 多轮对话优化：用户可对生成结果提出修改意见（如“鼓点太强”“结尾太突然”），Agent记住历史决策，重新规划并生成新版本
## 3. 音乐分析与MIDI生成
- 自动提取音频主旋律、和弦、结构（前奏/副歌）
- 生成原始MIDI文件作为中间表示
## 4. 乐器改编与铃声渲染
- 根据用户需求更换乐器音色（钢琴、吉他、弦乐等）
- 根据用户需求进行其他改编操作（升降调、改变节奏等）
- 智能截取最合适段落（自动或按用户指定长度）
- 合成结果音频文件（MP3铃声格式）

# 主要模块
## Agent核心
### Agent核心（智能体引擎）
- **规划器（Planner）**：将用户自然语言分解为有序动作序列（分析→MIDI→改编→渲染→质检）
- **执行器（Executor）**：按计划调用外部工具API，并处理异常
- **记忆模块（Memory）**：存储对话历史、中间产物（旋律、MIDI路径）、用户偏好（如“不喜欢大提琴”）
- **反思器（Reflector）**：根据质量评估结果或用户反馈，自动修正后续计划（如重新选择乐器）
- **工具调用网关（Tool Gateway）**：统一封装外部API（音频源、分析、MIDI生成、改编、渲染、质量评估），支持Mock与真实切换
### 其他支撑模块
- **音频源管理**：处理上传文件、链接解析
- **外部API客户端**：调用ChordMini、Librosa、FluidSynth等免费/自托管服务
- **数据库访问层**：管理任务、反馈、用户偏好等持久化数据
- **文件存储服务**：保存上传的原始音频和生成的铃声文件
