# 项目简介

# 核心功能
## 1. 用户输入
- 用户主动上传本地音频文件（支持MP3/WAV)
- （可选）用户直接搜索可用的音频
- 用户输入自然语言描述改编目标（如“温柔钢琴风”“清晨阳光般的铃声”）
## 2. 智能需求理解
- Agent自主解析模糊需求，转化为技术参数（乐器、节奏、长度、情绪）
- Agent根据模糊需求选择合适工具
- 多轮对话优化：用户可对生成结果提出修改意见（如“鼓点太强”“结尾太突然”），Agent记住历史决策，重新规划并生成新版本
## 3. 音乐分析与MIDI生成
- 自动提取主旋律、和弦、结构（前奏/副歌）
- 生成原始MIDI文件作为中间表示
## 4. 乐器改编与铃声渲染
- 根据用户需求更换乐器音色（钢琴、吉他、弦乐等）
- 根据用户需求进行其他改编操作（升降调、改变节奏等）
- 智能截取最合适段落（自动或按用户指定长度）
- 合成结果音频文件（MP3铃声格式）
